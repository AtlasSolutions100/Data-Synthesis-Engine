# PHASE 9D — Reconciliation + Check Register
*Largest build in the engagement so far. Self-contained (see scope boundary above). Sequence LAST and set time expectations with Mike.*

| ID | Tab | Edit | Acceptance criteria |
|---|---|---|---|
| **P9-REC-01** | Checking (COA) → register | Build a **check register** behind the Checking account: running list of checks written and deposits received, with a clear divider between cleared/past entries and forecasted/future entries. Entries flow in from bills paid and invoices received — Mike doesn't hand-key the register. | Checking register shows written checks + deposits with running balance; forecasted entries sit below a divider. |
| **P9-REC-02** | Reconcile (any account) | **Reconcile against an uploaded statement** (bank or vendor). Mike uploads the statement; the app matches entries; matched items get marked cleared/reconciled. Must reconcile to zero before closing the period. | Upload a vendor statement → matching lines mark as reconciled → period won't close until difference = 0. |
| **P9-REC-03** | Reconcile | **Partial-reconcile / "cleared" state.** If a reconciliation is started but can't finish (mismatch), it saves the in-progress cleared marks so Mike can return — he doesn't lose the work. | Start a reconcile, mark 5 of 8 lines, exit → return and the 5 cleared marks persist. |
| **P9-REC-04** | Reconcile | **"Unreconcile / redo previous month" — hard-check.** Mike can undo a completed reconciliation and redo it (with a confirmation guard). This is the fix for his single biggest QuickBooks pain: one bad entry and he can't roll back. | Click Unreconcile on a closed month → confirm guard → month reopens for redo; prior cleared marks are cleared for that period. |
| **P9-REC-05** | Reconcile | Reconciliation available for **any vendor account** Mike receives statements from (Home Depot, Lowe's, CED, Denver Breaker, Chase card), plus **checking and savings**. Not forced on accounts that don't need it. | Can initiate a reconcile from a vendor account and from checking/savings; other accounts don't demand it. |
| **P9-REC-06** | Vendor → write check | From a vendor, **write/record a check**: pick vendor → pull in open bills → select which to pay (and apply any credits) → mark "print later" or record a manual check number. **App does not print the physical check** (see boundary). | Select Denver Breaker → open bills load → choose bills + credits → save as "print later" or enter check # → recorded in register. |
| **P9-REC-07** | Vendor → write check | When recording a payment, **auto-pull open bills for that vendor** rather than making Mike add them one at a time. | Writing a check to a vendor auto-loads their open bills without a manual "add" step per bill. |
